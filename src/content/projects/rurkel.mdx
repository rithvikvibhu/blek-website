[Urkel](https://github.com/handshake-org/urkel) is an optimized and cryptographically provable key-value store. It is a sparse Merkle tree that powers the [Handshake](https://handshake.org) chain.

[liburkel](https://github.com/chjj/liburkel) is an alternative implementation of Urkel in C.

`rurkel` provides Rust bindings for `liburkel`.
